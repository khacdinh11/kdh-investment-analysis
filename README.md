# 🏆 Project Demonus - Finnovative Hackathon

**Thành tích:** Bán kết (Semi-finalist) cuộc thi Finnovative Hackathon 2026.

## 🌟 Giới thiệu
Dự án **KDH Investment Analysis** được phát triển nhằm giải quyết bài toán Phân tích và dự đoán đầu tư chứng khoán của công ty Khang Điền House (KDH). Chúng tôi sử dụng các kỹ thuật phân tích dữ liệu để đưa ra giải pháp tối ưu cho [đối tượng khách hàng].

## 📊 Các tính năng chính
- Phân tích và truy vấn dữ liệu thị trường tài chính (Bitcoin, HPG, FPT, VIC).
- Phân tích dữ liệu tài chính định lượng.
- Báo cáo nghiên cứu chi tiết về giải pháp Fintech tiềm năng.

## 🛠 Công nghệ sử dụng
- **Ngôn ngữ:** Python (Jupyter Notebook).

- **Báo cáo:** LaTeX/PDF.
